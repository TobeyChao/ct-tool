# Web 面板使用说明

面板把配表工具的日常操作搬进浏览器：导出、翻译、表格管理、日志与历史，
策划不需要接触命令行。

## 启动

先按 [README](README.md) 的安装流程激活项目 venv（Windows / macOS 一致）：

```bash
cd tool
# macOS
source .venv/bin/activate
# Windows PowerShell
.venv\Scripts\activate

ct panel --root ../gd
```

启动后会自动打开浏览器访问 `http://127.0.0.1:8000`。常用参数：

| 参数 | 说明 |
|------|------|
| `--root <dir>` | 工作区目录（默认当前目录，应指向 `gd/`） |
| `--port <n>` | 监听端口（默认 8000） |
| `--no-browser` | 不自动打开浏览器，手动访问地址 |

停止服务：在终端按 `Ctrl+C`。

## 页面说明

- **导出**：固定全量导出（全部表 × 全语言）。勾选“强制重建”可忽略增量缓存；
  导出过程显示 7 个步骤，可随时取消；导出中关闭页面会收到提示。
- **翻译 i18n**：选择表与语言后直接编辑译文；长文本点开即展开原文对照；
  “同步全部语言”让所有语言骨架对齐最新原文；“清理无主条目”删除已失效
  的残留译文（有内容才出现）；“全部表进度”查看整体翻译状态。
- **表格管理**：浏览 schema 表、查看详情、新增 / 编辑 / 删除表；
  模板漂移时提供“重建模板（保留数据）”。
- **日志**：按模块（导出 / 校验 / i18n / 模板 / 系统）筛选，实时追加。
- **历史**：最近 5 次导出记录。

## 与 CLI 的关系

面板复用 CLI 同一套用例与产物格式，两者行为一致，可随时混用。
CLI 的进阶能力（如 `--table` / `--lang` 局部导出）面板暂未开放，需要时
在终端直接运行对应命令即可。

## 常见问题

- **提示“工作区不可用”**：确认 `--root` 指向包含 `config/global.yaml` 的 `gd/` 目录。
- **导出失败**：页面会显示错误列表，点击“查看日志”跳转日志页定位具体行 / 列。
- **端口被占用**：换一个端口启动，如 `ct panel --port 8001`。
