## Purpose

提供浏览器访问的本地操作面板，让策划无需掌握命令行即可完成导出、翻译与表格管理，所有操作与 CLI 共享同一套行为与产物，保持每人本地一份工作区的工作方式。

## Requirements

### Requirement: 面板服务与工作区
面板 SHALL 以本地服务方式启动，浏览器打开后展示当前工作区（gd 根目录）与页签导航；工作区不可用或配置缺失时 SHALL 给出明确错误与修复指引，而不是空白页。

#### Scenario: 启动并打开面板
- **WHEN** 策划启动面板服务并访问本地地址
- **THEN** 页面展示导出 / 翻译 i18n / 表格管理 / 日志 / 历史五个页签，并显示当前工作区路径

#### Scenario: 工作区缺失
- **WHEN** 工作区目录或 `config/global.yaml` 缺失
- **THEN** 面板显示明确的错误信息与修复指引，不崩溃、不显示空白页

### Requirement: 导出操作
面板 SHALL 提供全量导出（全部表 × 全语言），支持强制重建；导出进行中 SHALL 展示主要步骤名称与当前状态，任何错误 SHALL 中止导出并在全局错误横幅中提示、指向日志页。

#### Scenario: 全量导出成功
- **WHEN** 策划点击"开始导出"且校验通过
- **THEN** 依次完成解析 / 校验 / i18n / JSON / FBS / Accessor / Bundle 七个步骤，完成后显示导出表数、语言与耗时

#### Scenario: 校验失败中止
- **WHEN** 数据校验存在错误
- **THEN** 导出中止，进度面板标记失败步骤与错误摘要，全局错误横幅提示并链接到日志页

#### Scenario: 导出中关闭页面
- **WHEN** 导出进行中策划尝试关闭页面或页签
- **THEN** 浏览器提示导出仍在进行，确认后停止任务并终止

### Requirement: 翻译管理与编辑
面板 SHALL 支持按表、语言、状态筛选翻译条目；译文可行内编辑并保存到对应 lang 文件；长文本以两行预览呈现，进入编辑时该行原文展开为完整文本以便对照。

#### Scenario: 编辑并保存译文
- **WHEN** 策划在某语言下填写译文并点击保存
- **THEN** 对应 `i18n/{lang}/{table}.json` 中该条目的 `text` 更新、`confirmed=true`，状态变为 translated

#### Scenario: 长文本展开对照
- **WHEN** 原文或译文长度超过单元格显示宽度
- **THEN** 单元格显示两行截断预览，点击进入编辑时该行原文展开为完整文本，失焦后收回

#### Scenario: 清理无主条目
- **WHEN** 当前表存在 orphan 条目
- **THEN** "清理无主条目"按钮出现并显示数量，二次确认后物理删除；无 orphan 时按钮不出现

### Requirement: 同步与进度总览
面板 SHALL 提供"同步全部语言"（刷新当前表所有语言的骨架）与"全部表进度"总览（按语言与表展示 translated / missing / stale 计数）。

#### Scenario: 同步全部语言
- **WHEN** 策划点击"同步全部语言"
- **THEN** 当前表所有语言的 lang 骨架按最新 source 更新：新增条目为 missing、原文变更为 stale、已删除条目标记为 orphan

#### Scenario: 全部表进度
- **WHEN** 策划打开"全部表进度"
- **THEN** 弹窗按语言与表展示翻译进度与各状态计数

### Requirement: 表格管理
面板 SHALL 提供 schema 表列表（表名搜索、模板状态筛选）与详情展示；新增 / 编辑 / 删除表 SHALL 通过弹窗完成；模板状态（已同步 / 漂移）SHALL 联动模板生成与重建能力。

#### Scenario: 新增表
- **WHEN** 策划在弹窗中填写表名、主键与字段定义并创建
- **THEN** 生成 schema 定义与 Excel 模板，列表出现新表且模板状态为"已同步"

#### Scenario: 编辑表并保存
- **WHEN** 策划修改字段定义并保存
- **THEN** schema 更新，并按新表头保留已有数据重建模板，状态回到"模板已同步"

#### Scenario: 模板漂移
- **WHEN** schema 在面板外被修改（如手动编辑 YAML 或拉取他人提交）
- **THEN** 列表与详情标记"模板漂移"，并提供"重建模板（保留数据）"操作

#### Scenario: 删除表
- **WHEN** 策划删除表并二次确认
- **THEN** schema 定义与 Excel 模板被移除，弹窗明确提示不可恢复

### Requirement: 日志与历史
面板 SHALL 提供按模块（导出 / 校验 / i18n / 模板 / 系统）筛选的日志页，以及保留最近 5 次导出记录的历史页。

#### Scenario: 日志按模块筛选
- **WHEN** 策划选择"校验"模块
- **THEN** 日志列表只显示校验模块的条目，其余模块隐藏

#### Scenario: 历史只保留最近五次
- **WHEN** 导出次数超过 5 次
- **THEN** 历史页只显示最近 5 次导出记录

### Requirement: 翻译表选择器
面板选择翻译表时 SHALL 仅列出含 i18n 字段的表；支持按表名搜索（自动聚焦）与按翻译状态胶囊筛选（全部 / 有缺失 / 有待审 / 已译完）；无匹配时 SHALL 显示明确的空态提示；弹窗 SHALL 可通过背景点击、关闭按钮或 Esc 键关闭，且不得留下不可见焦点或残留遮罩。

#### Scenario: 仅列出含 i18n 字段的表
- **WHEN** 策划打开“选择翻译表”弹窗
- **THEN** 列表仅展示含 i18n 字段的表，不含 i18n 字段的表不出现

#### Scenario: 按表名搜索
- **WHEN** 策划在搜索框中输入关键词
- **THEN** 列表实时仅保留名称包含该关键词的表

#### Scenario: 按翻译状态筛选
- **WHEN** 策划选择“有缺失”或“有待审”筛选胶囊
- **THEN** 列表仅保留相应状态计数大于 0 的表；“已译完”仅保留无缺失且无待审的表

#### Scenario: 无匹配空态
- **WHEN** 搜索或筛选后没有匹配的表
- **THEN** 列表区域显示“没有匹配的表”的空态提示，弹窗仍可关闭

#### Scenario: 选择与关闭
- **WHEN** 策划点击列表中的表
- **THEN** 切换到该表并刷新条目、弹窗关闭且不残留遮罩；点击背景、“关闭”按钮或 Esc 键同样关闭弹窗
