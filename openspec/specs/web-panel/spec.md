## Purpose

提供浏览器访问的本地操作面板，让策划无需掌握命令行即可完成导出、翻译与表格管理，所有操作与 CLI 共享同一套行为与产物，保持每人本地一份工作区的工作方式。

## Requirements

### Requirement: 面板服务与工作区
面板 SHALL 以本地服务方式启动，浏览器打开后展示侧栏模块导航（导出 / 翻译 i18n / 表格管理 / 日志 / 历史）；工作区根目录名 SHALL 在 `<740px` 顶栏呈现，导出页内容呈现工作区身份，桌面宽度不设全局顶栏；工作区不可用或配置缺失时 SHALL 给出明确错误与修复指引，而不是空白页。

#### Scenario: 启动并打开面板
- **WHEN** 策划启动面板服务并访问本地地址
- **THEN** 侧栏展示导出 / 翻译 i18n / 表格管理 / 日志 / 历史五个模块入口，导出页呈现工作区身份；窄屏（`<740px`）顶栏同时显示工作区根目录名

#### Scenario: 工作区缺失
- **WHEN** 工作区目录或 `config/global.yaml` 缺失
- **THEN** 面板显示明确的错误信息与修复指引，不崩溃、不显示空白页

### Requirement: 导出操作
面板 SHALL 提供全量导出（全部表 × 全语言），支持强制重建；导出进行中 SHALL 展示主要步骤名称与当前状态，任何错误 SHALL 中止导出并在全局错误横幅中提示、指向日志页。

#### Scenario: 全量导出成功
- **WHEN** 策划点击"开始导出"且校验通过
- **THEN** 依次完成解析 / 校验 / i18n / JSON / FBS / Accessor / Bundle 七个步骤，完成后显示导出表数、语言与耗时

#### Scenario: 校验失败中止
- **WHEN** 数据校验存在错误
- **THEN** 导出中止，进度面板标记失败步骤与错误摘要，全局错误横幅提示并链接到日志页

#### Scenario: 导出中关闭页面
- **WHEN** 导出进行中策划尝试关闭页面或页签
- **THEN** 浏览器提示导出仍在进行，确认后停止任务并终止

### Requirement: 翻译管理与编辑
面板 SHALL 支持按表、语言、状态筛选翻译条目；译文可行内编辑并保存到对应 lang 文件；长文本以两行预览呈现：原文列被截断时 SHALL 提供「展开/收起」尾标，译文可行内编辑（失焦保存），需要完整对照时 SHALL 通过译文单元格的全屏编辑角标打开全屏编辑弹窗（原文只读对照 + 大文本域），保存写回该条目并联动状态徽标；状态过滤与列显隐在切换表或行更新后 SHALL 重放。

#### Scenario: 编辑并保存译文
- **WHEN** 策划在某语言下填写译文并点击保存
- **THEN** 对应 `i18n/{lang}/{table}.json` 中该条目的 `text` 更新、`confirmed=true`，状态变为 translated

#### Scenario: 长文本展开对照
- **WHEN** 原文或译文长度超过单元格显示宽度且策划点击译文框的全屏编辑角标
- **THEN** 打开全屏编辑弹窗，原文完整只读对照；保存写回该条目（confirmed=true）并同步状态徽标与状态过滤；取消、Esc、背景点击或关闭按钮关闭且不写回；进入全屏前未提交的行内编辑先按行内规则提交

#### Scenario: 原文展开收起
- **WHEN** 原文超过两行被截断
- **THEN** 单元格右下角出现「展开/收起」尾标，点击展开完整原文、再点收起；未被截断的单元格不出现尾标；视口变化后重新评估截断

#### Scenario: 行内编辑保留
- **WHEN** 策划点击译文预览直接行内编辑并失焦
- **THEN** 译文按行内规则保存并更新状态，不强制经过全屏弹窗

#### Scenario: 清理无主条目
- **WHEN** 当前表存在 orphan 条目
- **THEN** "清理无主条目"按钮出现并显示数量，二次确认后物理删除；无 orphan 时按钮不出现

### Requirement: 翻译表列显隐
翻译工具栏 SHALL 提供「列」显隐菜单，可切换原文/译文/状态/操作四列的显示；勾选即时生效；点击菜单外部或按 Esc（无更高浮层时）关闭菜单且显隐状态保留；显隐状态在切换表与行更新后 SHALL 重放。

#### Scenario: 隐藏译文列
- **WHEN** 用户在列显隐菜单取消勾选「译文」
- **THEN** 表头与所有行的译文列立即隐藏，其余列不受影响

#### Scenario: 切表后列显隐保持
- **WHEN** 用户取消勾选「译文」列后切换到另一张表
- **THEN** 新表同样隐藏译文列，无需重新设置

#### Scenario: 菜单关闭不丢状态
- **WHEN** 菜单展开时用户点击页面其他区域或按 Esc（无更高浮层时）
- **THEN** 菜单关闭且列显隐状态保留

### Requirement: 同步与进度总览
面板 SHALL 提供"同步全部语言"（刷新当前表所有语言的骨架）与"全部表进度"总览（按语言与表展示 translated / missing / stale 计数）。

#### Scenario: 同步全部语言
- **WHEN** 策划点击"同步全部语言"
- **THEN** 当前表所有语言的 lang 骨架按最新 source 更新：新增条目为 missing、原文变更为 stale、已删除条目标记为 orphan

#### Scenario: 全部表进度
- **WHEN** 策划打开"全部表进度"
- **THEN** 弹窗按语言与表展示翻译进度与各状态计数

### Requirement: 表格管理
面板 SHALL 提供 schema 表列表（表名搜索、模板状态筛选）与详情展示；新增 / 编辑 / 删除表 SHALL 通过弹窗完成；模板状态（已同步 / 漂移）SHALL 联动模板生成与重建能力。

#### Scenario: 新增表
- **WHEN** 策划在弹窗中填写表名、主键与字段定义并创建
- **THEN** 生成 schema 定义与 Excel 模板，列表出现新表且模板状态为"已同步"

#### Scenario: 编辑表并保存
- **WHEN** 策划修改字段定义并保存
- **THEN** schema 更新，并按新表头保留已有数据重建模板，状态回到"模板已同步"

#### Scenario: 模板漂移
- **WHEN** schema 在面板外被修改（如手动编辑 YAML 或拉取他人提交）
- **THEN** 列表与详情标记"模板漂移"，并提供"重建模板（保留数据）"操作

#### Scenario: 删除表
- **WHEN** 策划删除表并二次确认
- **THEN** schema 定义与 Excel 模板被移除，弹窗明确提示不可恢复

### Requirement: 日志与历史
面板 SHALL 提供按模块（导出 / 校验 / i18n / 模板 / 系统）筛选的日志页，以及保留最近 5 次导出记录的历史页。

#### Scenario: 日志按模块筛选
- **WHEN** 策划选择"校验"模块
- **THEN** 日志列表只显示校验模块的条目，其余模块隐藏

#### Scenario: 历史只保留最近五次
- **WHEN** 导出次数超过 5 次
- **THEN** 历史页只显示最近 5 次导出记录

### Requirement: 翻译表选择器
面板选择翻译表时 SHALL 仅列出含 i18n 字段的表；支持按表名搜索（自动聚焦）与按翻译状态胶囊筛选（全部 / 有缺失 / 有待审 / 已译完）；无匹配时 SHALL 显示明确的空态提示；弹窗 SHALL 可通过背景点击、关闭按钮或 Esc 键关闭，且不得留下不可见焦点或残留遮罩。

#### Scenario: 仅列出含 i18n 字段的表
- **WHEN** 策划打开“选择翻译表”弹窗
- **THEN** 列表仅展示含 i18n 字段的表，不含 i18n 字段的表不出现

#### Scenario: 按表名搜索
- **WHEN** 策划在搜索框中输入关键词
- **THEN** 列表实时仅保留名称包含该关键词的表

#### Scenario: 按翻译状态筛选
- **WHEN** 策划选择“有缺失”或“有待审”筛选胶囊
- **THEN** 列表仅保留相应状态计数大于 0 的表；“已译完”仅保留无缺失且无待审的表

#### Scenario: 无匹配空态
- **WHEN** 搜索或筛选后没有匹配的表
- **THEN** 列表区域显示“没有匹配的表”的空态提示，弹窗仍可关闭

#### Scenario: 选择与关闭
- **WHEN** 策划点击列表中的表
- **THEN** 切换到该表并刷新条目、弹窗关闭且不残留遮罩；点击背景、“关闭”按钮或 Esc 键同样关闭弹窗
