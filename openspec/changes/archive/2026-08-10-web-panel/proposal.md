## Why

当前工具是纯 CLI，策划用起来门槛高：要跑命令、看退出码、手动拼参数，错误也不直观。需要一个浏览器里直接打开的本地面板，把导出、翻译、表格管理变成点按钮的操作，同时保留每人本地一份 `gd/` 的工作方式。

## What Changes

- 新增本地 Web 面板：浏览器打开即用，无前端构建链（Flask 纯 JSON API + Vue 3 无构建，`vue.global.prod.js` 本地托管）。
- 导出页：固定全量导出（全部表 × 全语言），支持强制重建；导出进行中展示 7 个主要步骤名称与当前进度；关闭页面时提示，强制关闭需先停止任务。
- 翻译页：按表/语言/状态筛选；译文行内编辑（短文本输入框、长文本两行预览 + 点击展开编辑，编辑时原文同步展开对照）；“同步全部语言”刷新当前表所有语言骨架；清理无主条目（有待清理项时按钮才出现，带数量）；“全部表进度”弹窗总览。
- 表格管理页：Schema 表列表 + 详情弹窗；新增/编辑/删除均走弹窗；模板状态（已同步/漂移）联动“生成模板/重建模板（保留数据）”；支持表名搜索与状态筛选。
- 日志页：独立页签，按模块（导出/校验/i18n/模板/系统）筛选，实时追加；全局错误横幅在任何页面出错时出现并指向日志页。
- 历史页：保留最近 5 次导出记录。
- 不涉及提交流程：策划导出完自行提交，面板不管 git。

## Capabilities

### New Capabilities
- `web-panel`: 浏览器面板能力——工作区状态、导出编排与进度、i18n 骨架与翻译管理、schema/表格管理、日志与历史展示。

### Modified Capabilities
- 无：CLI 与既有导出/校验/i18n 行为保持不变，面板只是新增的一层界面。

## Impact

- 新增后端：`tool/ct/web/`（Flask app + JSON API，复用 `ct/app/` 用例与事件原语）。
- 新增前端静态资源：`tool/web/`（Vue 3 无构建 + 本地托管 `vue.global.prod.js`）。
- 新增 Python 依赖：Flask（随 `tool/pyproject.toml` 一并声明）。
- 不改 CLI、不改导出产物格式、不改 schema 语义。
- 运行方式：策划在本机启动面板服务，浏览器打开 localhost 使用，每个策划各自持有本地 `gd/`。
