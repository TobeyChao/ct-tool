## MODIFIED Requirements

### Requirement: 表格管理（结构化编辑）

面板 SHALL 提供 schema 表列表（表名搜索、模板状态筛选、字段数/i18n 数、状态徽章）与详情展示；新增 / 编辑 / 删除表 SHALL 通过弹窗完成；模板状态（已同步 / 漂移）SHALL 联动模板生成与重建能力。字段编辑 SHALL 使用**结构化编辑器**（见 `schema-editor/web-editor` 与 `schema-editor/field-editor`）：字段行展示类型胶囊 + 字段名 + 状态 tags + 操作按钮，9 种类型（int32/int64/float/double/bool/string/enum/struct/vector）结构化编辑，字段增删/上移/下移/重命名，主键（Id）与 code（CodeName）字段锁定；编辑过程 SHALL 不出现 YAML 明文编辑框，保存 SHALL 有前端即时校验与后端 pydantic 校验双保险；列表为空 SHALL 显示空态与新增引导。删除表 SHALL 弹出确认模态（提示将删除 schema 定义与 Excel 模板、不可恢复、已导出产物与翻译文件不受影响），确认后删除并刷新列表。**从只读查看（表详情）进入编辑的，保存与取消 SHALL 回到表详情（只读查看）并重载最新数据；直接编辑（列表行「编辑」）才关闭**（2026-08-31 统一「保存/取消回上一级只读查看」语义）。

#### Scenario: 新增表
- **WHEN** 策划在弹窗中填写表名并通过结构化编辑器定义字段并创建
- **THEN** 生成 schema 定义与 Excel 模板，列表出现新表且模板状态为"已同步"

#### Scenario: 编辑表并保存
- **WHEN** 策划在结构化编辑器中修改字段定义并保存且校验通过
- **THEN** schema 更新，并按新表头保留已有数据重建模板，状态回到"模板已同步"

#### Scenario: 编辑表并保存（列布局变化不拒绝）
- **WHEN** 保存导致列布局变化（vector 定长列数/struct 展开/字段增删/列表头变化）且旧模板有数据行
- **THEN** 模板更新不拒绝，数据行原样保留（错列风险由用户自行核对转移，2026-08-30 用户确认）

#### Scenario: 从表详情编辑保存/取消回查看
- **WHEN** 策划从表详情（只读查看）进入编辑，保存或取消
- **THEN** 编辑模态关闭，回到表详情并重载最新数据（不关闭整个链路）

#### Scenario: 占行数变化保留数据
- **WHEN** 嵌套深度变化（header_rows 变化）且旧模板有数据行
- **THEN** 允许保留数据，数据行自动落到新表头（new header_rows + 1）之后，不错行

#### Scenario: 编辑期不接触 YAML
- **WHEN** 策划进行任何字段增删改操作
- **THEN** 界面始终为结构化控件（类型胶囊/下拉/复选框/输入框），无 YAML 文本框

#### Scenario: 模板漂移
- **WHEN** schema 在面板外被修改（如手动编辑 YAML 或拉取他人提交）
- **THEN** 列表与详情标记"模板漂移"，并提供"重建模板（保留数据）"操作

#### Scenario: 删除表带确认
- **WHEN** 策划删除表并二次确认
- **THEN** schema 定义与 Excel 模板被移除，弹窗明确提示不可恢复，列表刷新（空时显示空态）

#### Scenario: 空列表引导
- **WHEN** 工作区没有任何 schema 表
- **THEN** 列表区域显示「暂无表」与「新增表」引导按钮

## ADDED Requirements

### Requirement: 类型库页签

面板 SHALL 提供「类型库」页签：展示全局具名类型列表（按模块分组，行含 kind 徽章 / 类型名 / 摘要（enum 值或 struct 子字段）/ 引用计数），支持模块筛选、搜索与「新建类型」入口；类型查看/编辑/新建 SHALL 在类型模态中完成（详见 `schema-editor/type-library` 与 `schema-editor/field-editor` 的类型模态导航栈）；类型删除有引用保护（被引用时提示引用处）；类型库为空 SHALL 显示空态与「新建类型」引导。表编辑模态中字段引用类型处点「查看↗」/类型名 link SHALL 打开同一类型查看模态。

#### Scenario: 打开类型库
- **WHEN** 策划切换到「类型库」页签
- **THEN** 展示按模块分组的类型列表、模块筛选与新建入口，引用计数可点查看引用详情

#### Scenario: 删除被引用类型
- **WHEN** 策划删除仍被字段引用的类型
- **THEN** 删除被保护，界面提示引用处（表名.字段名）

#### Scenario: 类型库空态
- **WHEN** 类型库没有任何类型
- **THEN** 类型库页签显示「暂无类型」与「新建类型」引导按钮

#### Scenario: 动态新增模块
- **WHEN** 新建类型时目标模块不在下拉列表中
- **THEN** 可输入新模块名创建（写入新 `types/<模块>.yaml`），页签模块筛选同步出现该模块
